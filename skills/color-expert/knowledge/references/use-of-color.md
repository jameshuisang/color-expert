# use-of-color — semantic accessibility

Reviewed 2026-11-14. Selected passages only. Cross-media recommendations are project synthesis.
https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html
W3C's explanatory guidance for WCAG 2.2 SC 1.4.1 requires information not depend on color alone. Text, shape or other visible cues can preserve meaning. This is separate from text contrast. The understanding page is informative guidance explaining the criterion, not a complete conformance test.
