# Choosing a color model

Reference: CSS Color 4, reviewed 2026-11-14; a living technical specification.
https://www.w3.org/TR/css-color-4/

A wheel is a model, not a universal physical truth. Distinguish additive light, subtractive materials, perceptual organization and artistic conventions before comparing wheels. OKLCH is useful for perceptual editing; its lightness is not WCAG relative luminance. Equal numeric steps do not guarantee equal appearance in every viewing condition. Gamut and medium affect the available colors.

For the primary-source distinction between coordinate dimensionality, visualization, appearance and physical transport, use `color-science-foundations.md` (reviewed 2026-11-16). A flat wheel plus sliders can represent three coordinates; a three-dimensional display does not add missing spectral or viewing-condition information.
