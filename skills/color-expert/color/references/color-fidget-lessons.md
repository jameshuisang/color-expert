# Color exploration: source pointers and project practice

Inspiration: Color Nerd / Peter Donahue's Color Fidget video series. The earlier research reviewed available auto-captions, not the audiovisual demonstrations; caption errors and unverified claims remain possible. This note is project synthesis, not a reproduction of the course or an endorsement.

For our workflow, define the audience and intended reading before selecting colors. Explore hue, lightness and chroma together; assign roles and relative areas; then compare alternatives in the actual composition. Treat emotional associations and preferred proportions as hypotheses, not universal prescriptions. Keep artistic exploration separate from display gamut, pigment mixing and measured readability. A physical planning tool cannot supply evidence that a software interface is accessible or that a palette communicates successfully.
