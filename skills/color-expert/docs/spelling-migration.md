# Color naming

The current package and project skill use **color**: `color-expert`, with `SKILL.md`. Internal reference paths, route names, documentation and example strings use the same spelling. Official source link titles, URLs and license notices retain their original text.

The earlier candidate and original research are preserved separately; use this renamed whole folder for new work. This variant places all required files inside the installable skill directory. Installer verification is recorded separately; local installation does not imply a published GitHub repository.

Old route names containing `colour` are normalized when retrieving sources. New feedback uses `.color-learning`; an existing legacy ledger is reused rather than silently discarded. If both ledger directories exist, the tool stops for explicit reconciliation. Do not manually copy private ledgers into a distributable package.

Existing frozen review artifacts remain historical. Renaming a path or editing an artifact does not transfer its review to a new revision. New visual outputs require fresh review; the spelling migration is not a new aesthetics benchmark.
