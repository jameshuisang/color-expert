# Semantic decoding is a separate color competency

## Primary study checked

Schloss, Lessard, Walmsley and Foley (2018), [Color inference in visual communication: the meaning of colors in recycling](https://pmc.ncbi.nlm.nih.gov/articles/PMC5820393/), DOI10.1186/s41235-018-0090-y. Read the main methods, results and discussion; supplementary data and exact stimulus coordinates were not reanalysed.

The study tested how people inferred assignments between colored, unlabelled recycling bins and categories. Experiment1 (24 participants) favoured whole-set assignment over selecting each category's strongest color associate independently. Experiment2 (96 participants) compared optimized and deliberately ambiguous sets for six categories. Penalizing unintended associations improved assignment accuracy principally in the simultaneous matching task, not clearly in the single-selection task. Participants were young adults screened for normal color vision; stimuli used a characterized display. This supports testing competing meanings across a set, not assuming a universal color-to-meaning dictionary. It does not measure harmony, storytelling, preference or the performance of this expert. New UI/status domains and broader audiences require validation.

## Project application (proposed, not a study result)

When choosing categorical colors, ask both "what should this signify?" and "what else could the other colors signify in this set?" Evaluate the complete assignment rather than isolated plausibility. A coherent palette can be semantically confusing; an easily decoded set can be aesthetically poor. Keep these outcomes separate.

Use a separately frozen development protocol before generating diagnostic candidates. No semantic-decoding experiment is bundled or claimed completed by this candidate.

The color-only probe is an isolated diagnostic, never a production design recommendation. Production previews must retain explicit labels and status icons/shapes. A model can inspect actual pixels and report an assignment, but its accuracy is model behaviour, not human comprehension. Do not invent an empirical association matrix from model guesses, turn confidence into calibrated probability, or call a predictable mapping inherently correct. Correctness here means agreement with a designer's frozen intended mapping.

## Readiness and scope

Freeze the design, analysis, runtime/model identifiers, source hashes and renderer artifacts before generation. Failure to bind these blocks execution, rather than permitting retrospective preregistration. Existing visible briefs are development cases, not held-out transfer tests. No participants may be recruited, contacted or assessed under this plan; a separate approved human study would need an audience, sample-size rationale, consent/privacy process and exclusion/analysis plan.

Do not replace the contextual-harmony protocol with this test. Run semantic decoding alongside brief-fit, harmony, hierarchy and preference evidence, reporting each separately. No operational safety-critical task is involved.
